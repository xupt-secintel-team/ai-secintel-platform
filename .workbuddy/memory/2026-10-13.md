## 火狐详情页整屏变暗 Bug（用户报：查看情报详情时整个屏幕非常暗）
- 根因：`frontend/app.js` 的 `isNarrow()` 断点 1280 与 `styles.css` 的
  `@media (max-width:1200px)` 不一致 → 1201~1280px 区间 JS 开了遮罩(#mask z:80)、
  检查器却仍是桌面内联态(z-index:1) → 整屏被压暗。火狐窗口/站点缩放常落在该区间。
- 修复：① `isNarrow()` 1280→1200 与 CSS 对齐（附事故注释）；② `.inspector`
  z-index 1→100（防御纵深，palette 120/help 130/toast 200 仍更高）；
  ③ 新增 `@supports not (background:color-mix(...))` 旧内核回退
  （Chrome<111/Safari<15/Firefox<113/旧360、UC）。
- 多浏览器适配：index.html 加 X-UA-Compatible + renderer meta（360 强制极速内核）、
  ES5 特性检测 + #legacy 全屏降级提示（IE 等旧引擎）。
- 验证：Playwright Firefox 156 三档视口回归（1600/1250/1150）全过
  （1250 原事故区间：遮罩关、检查器 z=100、中心命中详情元素）；截图
  `测试报告/_fx_regress_*.png` + `_fx_narrow_open.js`。
