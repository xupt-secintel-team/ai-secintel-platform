## 三、口径与局限

- D1/D2/D4a 测的是「从 NVD 到语料」的**保真度**：NVD 后续重新分析（改分/改 CPE）会造成合理不一致，样例已列出供人工复核；
- D4b/D5 是**机械精度代理**（词面证据），偏保守——会低估真实准确率，不会高估；
- POC 维度已有独立评测（见 `测试报告/POC精度评测.md`；该报告标注了档位与口径 —— 快速档仅离线源、完整档含 GitHub 抓取，两者精度不可直接互换），本报告不重复计量；
- 综合判定建议取「八项均值」与「最弱维度」双口径：均值反映整体质量，最弱维度暴露短板。
