```
发现 → 人工确认（待确认项先复现）→ 派单 → 修复（附修复证据）
     → 复测 → 通过则关闭 / 不通过则退回并升级 → 风险接受须书面审批
```

| 环节 | 责任方 | 留痕要求 |
| --- | --- | --- |
| 确认 | 安全运维组 | 复现记录（截图/命令输出） |
| 派单 | 运维责任人 | 工单号与本报告发现编号一致 |
| 修复 | 资产责任人 | 变更单号 + 版本变更前后对比 |
| 复测 | 安全运维组 | 复扫报告 + 业务健康检查结果 |
| 关闭 | 安全运维组 | 复测通过记录 |
| 风险接受 | 业务负责人 | 书面审批（不接受默认关闭） |

**闭环证据链要求**：每条发现项须留齐「复现记录 → 变更单 → 修复后版本 → 复扫报告」四段证据，缺任一段不得关闭。
