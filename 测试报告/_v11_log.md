**★ 判据沉淀**
24. **`line-clamp` 在多断点重复声明时，胜负只看「谁在文件里更靠后」**：`.viewhead p` 曾有 1/2/3/4 四条（桌面默认 + hover + ≤980 + hover:none），级联后**最后一条 4 行胜出**，我在 768 里写的 2 行**根本不生效**（截图仍 3 行，一度误以为没写）。收敛这类属性必须先 grep 出**全部**出现位置再定契约。
25. **模块 CSS 里查「未定义令牌」会全量误报**：`var(--x)` 的 --x 定义在 styles.css 全局 `:root`，模块文件里看不到，属预期；同理 styles.css 的 `--c/--i/--vx/--ti` 是 JS 运行时写入，静态查必报。**只有「既不在本文件、也不在全局」才是真缺失**。
26. **内联 style 里的裸字号是令牌纪律的盲区**：批量替换脚本只扫 CSS，扫不到 JS 模板字符串里的 `style="font-size:10.5px"`。收尾必须单独 grep `font-size:\s*\d` 覆盖 **.js / .html**（本次抓到 5 处）。
27. **断点收敛别只加新档、要删旧档**：只在新位置排 6 档时，旧档（1500/1180/700）仍散落在后面的增强层里、**位置更靠后 → 覆盖新档**。「按宽度降序」只是必要条件，**还得保证每档只有一处**。
