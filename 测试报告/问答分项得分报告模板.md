# AI-SecIntel 问答评测 · 分项得分报告模板

> 用途：验收框架要求的「分项得分 + 不通过项 + 风险 + 结论」。**关键约束：各项指标必须逐项分开报告，不得合并成一个"准确率"。** 本模板跑完《问答基准测试集_100题》+ 双盲标注后填写。

## 七、最终结论

> 三选一：**通过 / 有条件通过 / 不通过**

- **通过**：所有必选项达标
- **有条件通过**：核心能力达标，存在 P1/P2 缺口（如 IOC 本体）但不影响主链路
- **不通过**：核心指标（准确率/幻觉率/推理链正确率）不达标，或证据物缺失
