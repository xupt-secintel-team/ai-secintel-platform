- 服务：`http://127.0.0.1:8940`　·　题量：**10 题**　·　模式：**模板模式（零 token）**
- 复跑命令：`python tools/评测问答深度.py --base http://127.0.0.1:8940`
- 判据只看**内容字段**（exploited / poc_count / 标题正则），与排序算法无关，不存在自证循环。

## 三、口径与局限

- **这是模板模式的分数，不是大模型生成质量的分数**。本评测回答的是：
  「在没有 LLM Key 的兜底路径上，系统给出的证据是否准、是否可回溯、是否编造」，
  而不是「大模型润色后的语言流畅度」——后者需要 Key 才能测，本次环境不具备。
- D3 只校验 CVE 编号这类**可机读实体**的保真性；叙述性文字的忠实度无法自动判定，
  这也是为什么系统同时提供引用回溯：让人可以逐条点开核对，而不是只信正文。
  口径说明：答案末尾「其他相关情报」会列出语料中真实存在、但未进入 top-5 引用卡的 CVE，
  这类不算编造 —— 判据是**去语料里查这个 CVE 存不存在**，而不是「在不在引用列表里」。
- D4 的上限是接口配置的 5 条引用，不是检索能力的上限（检索 @10 达 95%）。
