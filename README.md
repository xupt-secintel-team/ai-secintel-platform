## 核心功能
1. 多源公开漏洞情报自动同步，覆盖国内厂商专属漏洞
2. 本地漏洞知识库构建，支持资产富化与POC本地验证
3. 本地LLM智能体问答，检索增强生成漏洞分析与修复建议

## 快速部署
1. 克隆仓库，安装依赖：`pip install -r requirements.txt`
2. 复制配置模板，填写个人API密钥
3. 执行启动脚本即可本地运行
