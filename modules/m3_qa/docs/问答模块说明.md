# 情报问答模块（RAG）
AI-SecIntel系统模块3 — 自然语言漏洞情报问答

## 功能
- 自然语言提问，自动从漏洞库检索相关情报
- 大模型生成带CVE引用的结构化回答
- 多轮对话、多跳推理、不编造内容

## 目录结构
```
情报问答模块/
├── run.py              # 启动脚本（自动重启，崩了自动拉起）
└── qa/
    ├── config.py       # LLM/Embedding多供应商配置
    ├── retriever.py    # BM25+向量混合检索
    ├── generator.py    # RAG答案生成（带引用）
    ├── multi_hop.py    # 多跳问题拆解
    ├── vector_store.py # Chroma向量库封装
    ├── API.md          # 前端对接接口文档
    └── 测试记录.md     # 实跑测试记录和输出样例
```

## 启动方式
```bash
# 先启动主检索服务（在 aisec-D_1.2 目录下）
python server.py 8848

# 问答模块自动调用主服务的 /api/search 接口，不需要单独启动
```

## 前端对接
直接调 `POST http://127.0.0.1:8848/api/chat`
详细参数见 `qa/API.md`

## 配置LLM
编辑 `qa/config.py`，选择供应商（DeepSeek/豆包/通义/OpenAI），填入对应的API Key即可。
用户也可以在前端设置页自己填，不用改后端代码。
